## 答辩演示顺序

1. 消费者登录，展示六家商家、分类、商品和购物车。
2. 提交带收货信息的订单，在个人中心取消待发货订单。
3. 商家登录，展示经营图表，补充库存、修改价格和上下架。
4. 商家将订单从待发货更新为待收货。
5. 用户确认收货，订单变为已完成。
6. 超级管理员查看六家商家、14 件商品、用户和全平台订单。
7. 停用用户或商家，再尝试使用旧账号访问，验证权限失效。

## 范围说明

真实支付、第三方物流、推荐算法和多租户不属于本项目范围。系统使用模拟收货信息和演示经营数据完成交易闭环。
